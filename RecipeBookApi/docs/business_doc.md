# Бізнес-документ проєкту "Recipe Book API"

## 1. Назва системи та короткий опис
**Recipe Book API** — це веб-система для управління кулінарними рецептами, планування меню та пошуку інгредієнтів. 

Система дозволяє користувачам зберігати власні рецепти, шукати потрібні страви за наявними інгредієнтами, оцінювати рецепти інших авторів та формувати список покупок. Проєкт розробляється як модульний сервіс із чітким розділенням на веб-клієнт, REST API та базу даних.

## 2. Користувачі та ролі
* **Гість (Guest):** Переглядає публічні рецепти, здійснює пошук за назвою або категорією.
* **Авторизований користувач (User):** Створює, редагує та видаляє власні рецепти, додає страви до «Улюбленого», залишає коментарі та оцінки.
* **Адміністратор (Admin):** Модерує рецепти, керує категоріями та користувачами.

## 3. Основні сценарії використання (Use Cases)
1. **Перегляд каталогу рецептів:** Користувач відкриває головну сторінку та отримує список актуальних рецептів із фільтрацією.
2. **Створення нового рецепта:** Авторизований користувач заповнює форму (назва, категорії, інгредієнти, покрокова інструкція) та зберігає її.
3. **Пошук за інгредієнтами:** Користувач вказує наявні вдома продукти, система повертає відповідні рецепти.
4. **Управління списком обраного:** Додавання та видалення рецептів у власну колекцію.

## 4. Функціональні вимоги
* `FR-01`: Система повинна надавати REST API для CRUD-операцій над рецептами (`/items` або `/recipes`).
* `FR-02`: Система повинна підтримувати збереження даних у базі даних (SQLite / PostgreSQL).
* `FR-03`: Перевірка та валідація вхідних даних при створенні та оновленні рецепта.
* `FR-04`: Фільтрація рецептів за категоріями та пошук за ключовими словами.

## 5. Нефункціональні вимоги
* `NFR-01` (Швидкодія): Час відповіді API за нормального навантаження не повинен перевищувати 200 мс.
* `NFR-02` (Зручність): Простий та адаптивний веб-інтерфейс (HTML/JS).
* `NFR-03` (Надійність): Повернення уніфікованих помилок у форматі JSON із відповідними HTTP-статусами (400, 404, 500).

## 6. Обмеження (Out of Scope)
* Система НЕ обробляє реальні фінансові платежі.
	* Система НЕ здійснює автоматичний аналіз відеоінструкцій приготування.
