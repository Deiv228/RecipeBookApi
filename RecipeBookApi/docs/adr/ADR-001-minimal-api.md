# ADR-001: Вибір ASP.NET Core Minimal API для реалізації RecipeBookApi

* **Статус:** Прийнято
* **Дата:** 2026-11-11
* **Контекст:** Потрібно вибрати підхід для реалізації HTTP API в .NET для зберігання та обробки рецептів.

## Розглянуті варіанти
1. **ASP.NET Core Controller-based API:** Класичний підхід із атрибутами та контролерами.
2. **ASP.NET Core Minimal API:** Полегшений підхід із прямим мапінгом эндпоінтів.

## Рішення
Обрано **Minimal API**, оскільки проєкт має компактну структуру, потребує високої швидкості обробки запитів і низького накладного витрати пам'яті (overhead).

## Наслідки
* **Плюси:** Менше шаблонного коду (boilerplate), швидкий старт, висока продуктивність.
* **Мінуси:** При значному розростанні проєкту знадобиться групування эндпоінтів через `RouteGroupBuilder` або паттерн REPR.
