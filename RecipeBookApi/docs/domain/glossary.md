# Глосарій (Ubiquitous Language) — Recipe Book API

1. **Рецепт (Recipe):** Повний опис приготування страви, що включає назву, інструкцію, час приготування та список необхідних інгредієнтів.
2. **Інгредієнт (Ingredient):** Харчовий продукт або компонент, необхідний для приготування страви, із вказанням кількості та одиниці виміру.
3. **Категорія (Category):** Тематична група рецептів (наприклад: "Сніданки", "Десерти", "Супи").
4. **Користувач (User):** Зареєстрована особа в системі, яка може створювати власні рецепти та додавати інші в "Обране".
5. **Обране (Favorite):** Персональна колекція рецептів користувача для швидкого доступу.
